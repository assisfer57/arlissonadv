# Landing page — Dr. Arlisson Cucato Lins

Landing page estática, responsiva e preparada para SEO, Google Tag Manager, GA4 e conversões do Google Ads.

## Publicação

1. Abra `CONFIGURACAO-ANTES-DE-PUBLICAR.md`.
2. Preencha domínio, número/UF da OAB e IDs de mensuração.
3. Publique todos os arquivos preservando a pasta `assets`.
4. Cadastre `sitemap.xml` no Google Search Console.
5. Valide as conversões no modo Preview do Google Tag Manager.

Arquivo principal: `index.html`  
Política de privacidade: `politica-de-privacidade.html`
